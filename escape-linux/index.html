Operación Recuperación

En este escape room pondrás en práctica lo aprendido sobre Linux y descubrirás nuevos comandos para resolver los retos.

Durante el mantenimiento del laboratorio, las carpetas de un proyecto han quedado desorganizadas y el dispositivo con la copia de seguridad ha desaparecido. El profesor ha reunido los archivos que pudieron salvarse: entre ellos hay pistas para encontrarlo. Tu misión es reconstruir las carpetas, recuperar la información y localizar el dispositivo.

Descargar escape_fie.zip

Para mantener el reto, evita buscar soluciones en el código del juego. Solo tendrás que editar la primera línea, como se explica abajo.

Prepara la consola

Abre una terminal en la carpeta donde hayas descargado el ZIP. Sigue estos pasos para preparar el juego; después, su consola te guiará por los retos.

1. Descomprime y entra en la carpeta

unzip escape_fie.zip
mv escape_fie ~/escape_fie
cd ~/escape_fie
ls

Con unzip extraes el paquete y con mv lo mueves a tu directorio personal, representado por ~ y también llamado HOME. Después, cd te sitúa en la carpeta del juego y ls muestra su contenido: comprueba que aparece iniciar.py.

Si has descomprimido el ZIP directamente en tu HOME, omite mv. Puedes usar pwd para comprobar en qué carpeta estás.

2. Localiza Python

which python3

El juego está escrito en Python y necesita su intérprete para ejecutarse. which te indica dónde está instalado; conserva la ruta que aparezca, porque la usarás en el siguiente paso.

3. Indica el intérprete

nano iniciar.py

Este comando abre iniciar.py en el editor Nano. En la primera línea, sustituye #!RUTA_PYTHON por #! seguido de la ruta que has obtenido. Si era /usr/bin/python3, quedaría así:

#!/usr/bin/python3

Esta línea se llama shebang e indica a Linux qué intérprete debe utilizar. Guarda el cambio y sal del editor con estas teclas:

Ctrl+O guardar Enter confirmar Ctrl+X salir

4. Añade el permiso de ejecución

ls -l iniciar.py
chmod +x iniciar.py
ls -l iniciar.py

Antes de arrancarlo, debes permitir que Linux ejecute el archivo. El primer ls -l muestra sus permisos; chmod +x añade el de ejecución y el segundo ls -l te permite comparar el resultado.

En los permisos, r permite leer, w escribir y x ejecutar. Se agrupan para el propietario, el grupo y los demás usuarios; un - indica que ese permiso no está concedido.

Ejemplo: -rw-r--r--
TipoPropietarioGrupoOtros
- archivorw-r--r--

El primer carácter indica el tipo de archivo. En este ejemplo, el propietario puede leer y escribir, pero todavía no ejecutar. Tras chmod +x podría aparecer -rwxr-xr-x: fíjate en las nuevas x.

5. Arranca el juego

./iniciar.py

Con ./ indicas que quieres ejecutar el archivo que está en la carpeta actual. Aparecerá la consola de recuperación con tu primer objetivo. Déjala abierta y prepara otras dos terminales.

Trabaja con tres terminales

1 · CONSOLA

Aquí permanece abierto el juego. Consulta los objetivos y observa cómo se actualiza tu progreso.

2 · PAQUETE ORIGINAL
cd ~/escape_fie

Utiliza esta terminal para explorar los archivos originales y consultar las pistas.

3 · RECONSTRUCCIÓN
cd ~

Desde tu HOME, crea ~/FIE_RECOVERY y reconstruye su contenido siguiendo los objetivos del juego.

Cambiar de carpeta en una terminal no cambia la ubicación de las demás, aunque todas comparten los archivos. La consola comprueba tus cambios y avanza cuando completas cada objetivo; las instrucciones permanecen visibles mientras trabajas.

Una ventana de 80 columnas y 40 filas permite ver cómodamente la consola. Si es más pequeña, puedes desplazarte para leer.

Si quieres saber más, abre el manual con man comando, por ejemplo man chmod. Usa las flechas o el espacio para avanzar, /palabra para buscar y q para salir. Para consultar cd, utiliza help cd.
