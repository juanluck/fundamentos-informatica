Operación Recuperación

Un procedimiento de recuperación quedó incompleto durante una intervención de mantenimiento. Conservamos un paquete de emergencia. Tu misión es reconstruir el sistema y localizar el dispositivo físico de respaldo.

Estructura de trabajo DAÑADA
Equipo NO IDENTIFICADO
Expediente BLOQUEADO
Dispositivo NO LOCALIZADO
Descargar escape_fie.zip

No abras ni inspecciones el código fuente del paquete: forma parte del reto.

0 · Preparar la consola

Descarga el ZIP y abre una terminal en la carpeta donde lo hayas guardado. Ejecuta cada comando y observa su efecto antes de pasar al siguiente. Escribe solo el comando: el indicador de la terminal, como ~$, no se copia.

1. Descomprime el paquete y colócalo en tu HOME

unzip escape_fie.zip

unzip extrae los archivos del ZIP y crea la carpeta escape_fie en el directorio actual. Verás los nombres de los archivos que se van extrayendo.

mv escape_fie ~/escape_fie

mv mueve la carpeta: el primer argumento es el origen y el segundo el destino. ~ representa tu directorio personal, también llamado HOME. Si ya has descomprimido el paquete directamente en tu HOME, omite este comando: la carpeta ya está donde debe estar.

cd ~/escape_fie
ls

cd cambia el directorio de trabajo de esta terminal; no mueve los archivos. ls lista su contenido. Comprueba que aparece iniciar.py. Puedes ejecutar pwd para ver la ruta completa del directorio en el que estás.

A partir de ahora el paquete original estará en ~/escape_fie. El sistema reconstruido se creará aparte, directamente bajo tu directorio HOME.

Para ampliar, consulta man unzip, man mv o man ls. Dentro del manual, usa las flechas o el espacio para avanzar, /palabra para buscar, n para la siguiente coincidencia y q para salir. Para cd, integrado en Bash, utiliza help cd.

2. Averigua dónde está Python 3

El archivo iniciar.py contiene instrucciones escritas en Python. El intérprete Python 3 es el programa que las ejecuta; primero vamos a localizarlo.

which python3

which busca el ejecutable en los directorios de PATH, la lista de lugares donde se buscan los comandos. Obtendrás una ruta similar a /usr/bin/python3. Conserva exactamente la que aparezca en tu equipo: la utilizarás en el siguiente paso. Para ampliar: man which.

3. Edita la primera línea de iniciar.py

nano iniciar.py

nano abre el archivo en un editor de texto dentro de la terminal. Vamos a modificar únicamente la primera línea para indicar dónde está el intérprete.

La primera línea contiene:

#!RUTA_PYTHON

Sustitúyela por #! seguido de la ruta obtenida con which python3. Por ejemplo:

#!/usr/bin/python3

Esta línea se llama shebang: #! indica que la ruta que le sigue identifica el intérprete. Al ejecutar el archivo directamente, Linux utilizará ese programa para leer sus instrucciones. La ruta del ejemplo solo sirve si coincide con la que has obtenido.

Ctrl+O guardar Enter confirmar Ctrl+X salir

Al pulsar Ctrl+O, Nano te pregunta con qué nombre guardar; pulsa Enter para conservar iniciar.py. Después, Ctrl+X cierra el editor y devuelve el control a la terminal. Para ampliar: man nano.

4. Haz ejecutable el programa

Primero, observa los permisos actuales. Tener un archivo con código no implica que Linux permita ejecutarlo directamente.

ls -l iniciar.py

ls muestra información del archivo; la opción -l pide el formato largo. La línea incluye el tipo y los permisos, el propietario, el grupo, el tamaño, la fecha y el nombre. Fíjate en sus primeros caracteres, que podrían ser:

-rw-r--r--

El primer carácter - indica que es un archivo normal; en un directorio aparecería d. Los nueve caracteres siguientes se leen en tres grupos:

Cómo leer el ejemplo -rw-r--r--
GrupoPermisosQué permite sobre este archivo
Propietariorw-Leerlo y modificarlo; todavía no ejecutarlo.
Grupor--Leerlo; no modificarlo ni ejecutarlo.
Otros usuariosr--Leerlo; no modificarlo ni ejecutarlo.

En cada grupo, r (read) permite leer el contenido; w (write), modificarlo; y x (execute), ejecutarlo. Un - en cualquiera de esas posiciones indica que ese permiso no está concedido. Por tanto, la primera r del ejemplo es el permiso de lectura del propietario.

Ahora, añade el permiso de ejecución.

chmod +x iniciar.py

chmod modifica los permisos; + significa añadir y x es el permiso de ejecución. Cambias los permisos del archivo, no su contenido. Normalmente el comando termina sin mostrar ningún mensaje.

Por último, comprueba qué ha cambiado.

ls -l iniciar.py

Compara el resultado con el anterior. Con una configuración habitual, el ejemplo pasaría de -rw-r--r-- a -rwxr-xr-x: han aparecido las x. Los permisos exactos pueden variar según la configuración del equipo; comprueba especialmente la x del propietario, en el primer grupo.

Para ampliar: man ls y man chmod. El segundo explica cómo expresar otros cambios de permisos. Recuerda que q permite salir del manual.

5. Inicia la recuperación

./iniciar.py

. representa el directorio actual; ./iniciar.py pide ejecutar el archivo que está aquí. Linux comprueba el permiso de ejecución y utiliza el intérprete indicado por el shebang. Debería aparecer la consola de recuperación.

Si aparece Permission denied, revisa el permiso x. Si el error señala que el intérprete no existe, comprueba que la primera línea coincide con la ruta devuelta por which python3.

En cuanto arranque la consola, esta página deja de darte instrucciones.

Deja esa terminal abierta y prepara dos terminales adicionales.

Organización recomendada

TERMINAL 1 · CONTROL
~/escape_fie$ ./iniciar.py

Lee. No trabajes aquí.

TERMINAL 2 · PAQUETE
~/escape_fie$

Ejecuta cd ~/escape_fie para consultar los materiales originales.

TERMINAL 3 · SISTEMA
~$

Ejecuta cd ~ para situarte en tu HOME. Reconstruye aquí el sistema de respaldo.

Cada terminal mantiene su propio directorio de trabajo: un cd en una no cambia la ubicación de las demás. Los archivos sí son compartidos: una copia creada en una terminal puede verse desde otra. Usa pwd cuando necesites comprobar dónde estás.

La consola de recuperación supervisará automáticamente los cambios en ~/FIE_RECOVERY y avanzará cuando detecte una solución correcta.

Cada pantalla empieza por el OBJETIVO, justo debajo del progreso. Después aparecen ORIGEN y DESTINO, o la ubicación o el archivo sobre el que actuar. Siguen CÓMO HACERLO (con las pistas), COMPRUEBA (lo que debes observar tú), ESTADO (lo que ha detectado la consola) y PARA AMPLIAR (el manual).

Las instrucciones permanecen visibles hasta que completes cada objetivo. Cuando tengas que leer el informe de LibreOffice, la consola mostrará cómo abrirlo y cómo confirmar desde otra terminal que has terminado. Puedes leerlo sin límite de tiempo.

Para ver cómodamente la consola, utiliza una ventana de al menos 80 columnas y 40 filas (puedes maximizarla o reducir el tamaño de letra). En ventanas pequeñas, las instrucciones se conservan como texto por el que puedes desplazarte. Cada herramienta nueva incluye una explicación, un ejemplo y una referencia al manual: man comando. Pulsa q para salir del manual.
