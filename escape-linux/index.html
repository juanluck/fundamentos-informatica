Operación Recuperación

Un escape room para reforzar lo aprendido sobre Linux y descubrir nuevos comandos.

Esta mañana, el laboratorio ha amanecido con los archivos de un proyecto desordenados. Solo queda un paquete de emergencia y una pista: entre sus documentos están las instrucciones para encontrar la copia de seguridad. Reconstruye las carpetas, sigue las pistas y encuentra el dispositivo.

Descargar escape_fie.zip

Para mantener el reto, no busques soluciones en el código. Edita solo la primera línea indicada abajo.

Prepara la consola

Abre una terminal donde hayas descargado el ZIP y ejecuta los comandos en orden.

1. Descomprime y entra en la carpeta

unzip escape_fie.zip
mv escape_fie ~/escape_fie
cd ~/escape_fie
ls

unzip descomprime; mv mueve; cd cambia de carpeta; ls muestra su contenido. ~ es tu directorio personal (HOME). Comprueba que aparece iniciar.py.

Si descomprimes directamente en tu HOME, omite mv. Para saber dónde estás: pwd.

2. Localiza Python

which python3

which muestra la ruta del programa. Guarda el resultado: Python será el intérprete que ejecute el juego.

3. Indica el intérprete

nano iniciar.py

nano abre el editor. Sustituye #!RUTA_PYTHON por #! seguido de la ruta obtenida antes. Por ejemplo:

#!/usr/bin/python3

Esta primera línea, llamada shebang, indica a Linux qué intérprete debe usar.

Ctrl+O guardar Enter confirmar Ctrl+X salir

4. Añade el permiso de ejecución

ls -l iniciar.py
chmod +x iniciar.py
ls -l iniciar.py

El primer ls -l muestra los permisos. chmod +x añade el de ejecución. El último ls -l permite comprobar el cambio.

r: leer · w: escribir · x: ejecutar · -: permiso ausente.

Ejemplo: -rw-r--r--

Tras el cambio podría aparecer -rwxr-xr-x. Comprueba que el propietario tiene x.

5. Arranca el juego

./iniciar.py

./ indica que ejecutas un archivo del directorio actual. Aparecerá la consola con tu primer objetivo.

Trabaja con tres terminales

1 · CONSOLA

Deja el juego abierto. Lee aquí los objetivos y el progreso.

2 · PAQUETE ORIGINAL
cd ~/escape_fie

Consulta los archivos y las pistas.

3 · RECONSTRUCCIÓN
cd ~

Construye ~/FIE_RECOVERY siguiendo el juego.

Cada terminal tiene su propia ubicación, pero todas comparten los archivos. La consola detecta tus cambios y avanza automáticamente; puedes leer sin prisa.

Consola recomendada: 80 columnas × 40 filas. En ventanas pequeñas, desplázate para leer.

Para ampliar: man comando abre el manual. Flechas o espacio para avanzar, /palabra para buscar y q para salir. Para cd: help cd.
