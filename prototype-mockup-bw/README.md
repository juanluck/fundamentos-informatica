# Puerta A — Reconstrucción estructural de 1.2

Esta carpeta implementa únicamente la **Fase 3 / Puerta A** del protocolo de ajuste al mockup.

Objetivo: comprobar que la jerarquía, densidad, retícula y peso relativo de los bloques recuerdan al mockup aprobado **sin depender de color, ilustraciones finales, JavaScript ni Quarto**.

## Deliberadamente ausente

- color;
- fuentes definitivas;
- ilustraciones finales;
- interactividad;
- Quarto;
- navegación del libro;
- componentes reutilizables.

## Regla

Si la estructura en escala de grises no se parece al mockup, no se avanza a tipografía ni color.
