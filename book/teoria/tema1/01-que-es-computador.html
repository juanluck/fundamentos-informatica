LECCIÓN 1.1

¿Qué es realmente
un computador?

¿Qué ocurre entre los datos que introducimos y el resultado que recibimos, y qué hace que ese proceso pueda realizarse automáticamente?

1. Informática: tratar información automáticamente

La Informática reúne los conocimientos científicos y las técnicas que hacen posible el tratamiento automático de la información mediante computadores electrónicos.

Información→tratamiento automático→Información
La Informática es la disciplina.
El computador es la máquina.

2. Un computador recibe, transforma y devuelve

Un computador es una máquina capaz de aceptar datos de entrada, efectuar con ellos operaciones lógicas y aritméticas y proporcionar la información resultante a través de una salida.

3. El programa dirige el proceso

El tratamiento se realiza sin la intervención continua de un operador humano y bajo el control de un programa de instrucciones previamente almacenado en el propio computador.

1Entrada. Llegan los datos sobre los que se va a trabajar.
2Proceso. El programa determina qué operaciones debe efectuar la máquina.
3Salida. El computador devuelve la información resultante.
Automático no significa “sin instrucciones”: significa que la máquina sigue el programa sin que una persona dirija cada operación.

4. El modelo que usaremos a partir de ahora

Para entender un computador iremos abriendo poco a poco esta caja: primero veremos cómo representa la información, después qué componentes contiene y finalmente cómo cooperan para ejecutar un programa.

datos + instrucciones→computador→resultado
