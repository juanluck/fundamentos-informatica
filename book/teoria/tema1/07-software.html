LECCIÓN 1.7

¿Qué papel juega
el software?

El hardware puede realizar operaciones, pero necesita instrucciones que indiquen qué hacer, en qué orden y con qué datos.

1. De una instrucción a un programa

En el material docente, una instrucción es un conjunto de símbolos que representa una orden de operación o tratamiento para el computador. Un programa es un conjunto ordenado de instrucciones que se proporcionan a la máquina para indicarle las operaciones o tareas que se desea que realice.

2. Traducción: del lenguaje de alto nivel al lenguaje máquina

El esquema original separa dos momentos. Primero, un programa traductor transforma el programa escrito por el usuario en lenguaje de alto nivel en un programa en lenguaje máquina que el computador pueda ejecutar.

3. Ejecución: programa + datos → resultados

Una vez traducido, el programa en lenguaje máquina y los datos del usuario se entregan al computador. Su ejecución produce los resultados del programa.

4. El software como herramienta de ingeniería

El material distingue entre aplicaciones generales —ofimática, procesamiento sencillo de datos, hojas electrónicas— y aplicaciones específicas de ingeniería para facilitar el diseño, la fabricación, las pruebas, el control y la monitorización.

5. Del clic al resultado

Ya podemos recorrer el hilo completo del tema: una tarea se expresa mediante software; el programa y sus datos se representan con bits; CPU y memoria los almacenan y procesan; los buses permiten intercambiarlos; y la ejecución repite operaciones sincronizadas hasta producir un resultado.

información→bits→componentes→buses→ejecución→resultado
Ya no estamos viendo piezas aisladas: tenemos un modelo mental completo del computador.
