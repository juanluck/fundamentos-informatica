LECCIÓN 1.4

¿Cómo se comunican
sus componentes?

CPU y memoria necesitan intercambiar continuamente información. Para hacerlo usan conjuntos de líneas que transportan bits: los buses.

1. Un bus es un camino compartido

En el modelo básico del material docente distinguimos dos buses fundamentales entre CPU y memoria: el bus de datos y el bus de direcciones. Uno transporta la información; el otro indica dónde debe leerse o escribirse.

2. Bus de datos: ¿cuánta información viaja?

El material original relaciona directamente el ancho del bus de datos con la longitud de palabra. Si el computador trabaja con palabras de 32 bits, el bus de datos debe poder transferir esos 32 bits.

palabra de 32 bits→bus de datos de 32 bits

3. Bus de direcciones: ¿a cuántos lugares puedo apuntar?

Con n bits de dirección pueden formarse 2n combinaciones. Si cada combinación identifica una palabra de memoria, un bus de direcciones de n bits puede seleccionar m = 2n palabras.

2n= m palabras direccionables
n = log2 mbits de dirección
Es la misma idea de la lección 1.2: más bits → más combinaciones. Ahora las combinaciones son direcciones.

4. 32 Mbytes y palabras de 32 bits

Enunciado. Un computador tiene una capacidad máxima de memoria de 32 Mbytes y está organizado en palabras de 32 bits. ¿Cuál debe ser el ancho del bus de datos y cuántos bits necesita el bus de direcciones?

Resolución
1El bus de datos debe poder transferir una palabra completa: 32 bits.
232 Mbytes = 32 × 220 bytes = 225 bytes.
3Una palabra de 32 bits ocupa 4 bytes = 22 bytes; por tanto hay 223 palabras.
4Para seleccionar 223 palabras hacen falta 23 bits de dirección.
Bus de datos: 32 bitsBus de direcciones: 23 bits

Mover información es solo el principio. Ahora veremos cómo la CPU encadena esos movimientos y operaciones para ejecutar un programa.
