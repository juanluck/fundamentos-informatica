# Prototipo editorial v2 — Lección 1.2

Este prototipo se ha construido deliberadamente **fuera de Quarto** para validar primero el lenguaje visual del libro.

## Objetivo

Validar una única página real antes de crear un sistema reutilizable:

- composición editorial y no de dashboard;
- Quarto ausente de la interfaz;
- jerarquía tipográfica fuerte;
- ilustración y diagramas integrados en la narración;
- pocas superficies en forma de caja;
- interactividad solo cuando añade comprensión;
- comportamiento responsive.

## Archivos

- `index.html`: contenido y semántica de la lección.
- `styles.css`: sistema visual aislado.
- `app.js`: explorador de bits y solución plegable.

No debe trasladarse a Quarto hasta superar revisión visual en navegador.
