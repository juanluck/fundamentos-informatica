# Guía visual — v0.1

## Dirección visual

Identidad propia, cálida, visual y didáctica. La referencia elegida es la propuesta D del prototipo inicial.

## Prioridades

1. Legibilidad prolongada.
2. Jerarquía clara.
3. Reconocimiento inmediato de componentes didácticos.
4. Color con función, no como decoración gratuita.
5. Buen comportamiento móvil.
6. Web primero; PDF coherente y utilizable tanto en pantalla como impreso.

Esta paleta es provisional hasta validar el sandbox renderizado.

## Tipografía inicial

- Texto y encabezados: serif editorial.
- Navegación y metadatos: sans serif.
- Código: monoespaciada proporcionada por el tema de Quarto.

La familia definitiva se decidirá después de comparar el render real en web y PDF.
