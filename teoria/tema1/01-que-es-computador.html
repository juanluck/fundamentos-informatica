1.1 · ¿Qué es un computador?

LECCIÓN 1.1

¿Qué es un computador?

Antes de hablar de CPU, memoria o programas, necesitamos una idea sencilla que nos permita reconocer qué tienen en común dispositivos muy diferentes.

1. Una máquina que transforma información

Un portátil, un teléfono, una consola o la centralita de un automóvil tienen aspectos y usos distintos. Sin embargo, todos pueden entenderse inicialmente con un mismo esquema:

Entradadatosteclas, imagen, medida…
→
Procesamientocomputadoraplica instrucciones
→
Salidaresultadopantalla, sonido, acción…

Concepto clave

Un computador es una máquina programable capaz de recibir, almacenar y procesar datos para obtener resultados.

2. Dato no significa todavía información

23

¿Qué significa?

Podría ser una temperatura, una edad, el número de estudiantes de un grupo o una dirección de memoria. El símbolo por sí solo no basta.

Un dato es una representación. Se convierte en información cuando sabemos cómo interpretarlo dentro de un contexto.

La representación y el significado no son la misma cosa.

3. Codificar es acordar una representación

No hace falta empezar por el binario. Un semáforo ya utiliza un código.

Rojodetenerse
Verdeavanzar

La señal física y su significado están relacionados mediante una regla de interpretación. En informática ocurre lo mismo: un patrón de bits puede significar una letra, un número o una instrucción dependiendo del código utilizado.

Importante

El computador manipula representaciones físicas. El significado aparece cuando interpretamos esas representaciones según unas reglas compartidas.

4. Hardware y software

HARDWARE

Lo que puede hacer físicamente

Procesador, memoria, almacenamiento, sensores, pantalla y demás componentes materiales.

SOFTWARE

Lo que le pedimos que haga

Programas e instrucciones que utilizan los recursos del hardware para realizar una tarea.

Ejercicio 1.1 ● Básico

Entrada, procesamiento y salida

Para cada situación, identifica una posible entrada, el procesamiento y la salida:

  1. una calculadora suma dos números;
  2. una cámara de móvil toma una fotografía;
  3. una aplicación de navegación calcula una ruta.

Solución

En una calculadora, los números y la operación son la entrada; realizar la suma es el procesamiento; el valor mostrado es la salida.

En una cámara, la luz captada por el sensor es una entrada; el sistema procesa las medidas del sensor; la imagen almacenada o mostrada es una salida.

En una aplicación de navegación, origen, destino y datos cartográficos son entradas; el cálculo de la ruta es el procesamiento; la ruta propuesta es la salida.

IDEA ESENCIAL

Un computador no es “una máquina que entiende”. Es una máquina capaz de transformar representaciones siguiendo instrucciones.
