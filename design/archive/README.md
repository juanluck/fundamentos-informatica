# Archivo histórico de diseño

Este directorio conserva decisiones y prototipos de ramas experimentales que ya no forman parte del flujo de desarrollo activo.

La fuente oficial del libro es `main`. Los documentos de este archivo **no son especificaciones vigentes** salvo que un documento activo de `design/` los cite expresamente.

## maqueta-quarto-v01

Rama experimental inicial de Quarto. Su implementación quedó superada por la macroversión actual del Tema 1 y por el Design System v1.

Se conservan aquí únicamente los documentos conceptuales que siguen siendo útiles para entender la evolución del proyecto:

- `PEDAGOGY.md`
- `STYLE_GUIDE.md`
- `COMPONENTS.md`
- `VISUAL_AUDIT_TEMA1.md`

No se conserva su código Quarto, filtros, estilos ni assets porque fueron prototipos intermedios y la implementación vigente se encuentra en las fuentes actuales del libro.

Documentos activos relacionados:
- `../DESIGN_SYSTEM_V1.md`
- `../TEMA1_MACROVERSION_V1.md`
- `../QUARTO_MARKDOWN_AUTHORING.md`
