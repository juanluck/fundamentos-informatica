¿Cómo puede un computador representar una letra, una fotografía o una canción utilizando únicamente dos estados?

1. Dos estados, muchas posibilidades

Un circuito digital solo puede encontrarse en dos estados distintos, que representamos como 0 y 1. A partir de estos dos estados podemos construir toda la información.

2. El bit y las combinaciones

Un bit (binary digit) es la unidad mínima de información y puede tomar dos valores: 0 o 1. Si combinamos varios bits, podemos representar muchas más posibilidades.

Con n bits podemos representar 2n combinaciones.

4. ¿Cuántos bits necesito?

Si quiero representar N elementos distintos, necesito el menor número n de bits tal que 2n ≥ N. Matemáticamente:

n = ⌈log2 N⌉
